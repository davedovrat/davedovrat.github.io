Why should I care?

“The source is on GitHub. Can I use it?”

Not necessarily. Public source code is not automatically open source. A license is what grants permissions to use, modify and redistribute.

A license answers practical questions

  • Can I use it commercially?
  • Can I modify and redistribute it?
  • Must I publish my source code?
  • Must my derivative use the same license?
  • Is there an explicit patent grant?
  • What notices must I preserve?

A selection heuristic

Maximum reuse:

MIT / BSD / ISC

Permissive, explicit patent terms:

Apache 2.0

Modifications to files/library remain open:

MPL / LGPL

Distributed derivatives remain open:

GPL

Modified hosted/network versions share source:

AGPL

Licensing content, not code:

Creative Commons / CC0
